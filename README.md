# Projeto de Geração de Gráficos em Python

Este repositório contém os scripts em Python para a geração de 8 gráficos distintos a partir dos ficheiros Excel fornecidos.

## Estrutura do Projeto

```text
.
├── dados/
│   ├── dados_barras.xlsx
│   ├── dados_boxplot.xlsx
│   ├── dados_dispersao.xlsx
│   ├── dados_frequencia.xlsx
│   ├── dados_heatmap.xlsx
│   ├── dados_linhas.xlsx
│   ├── dados_pizza.xlsx
│   └── dados_regressao.xlsx
├── 01_grafico_barras.py
├── 02_grafico_boxplot.py
├── 03_grafico_dispersao.py
├── 04_grafico_frequencia.py
├── 05_grafico_heatmap.py
├── 06_grafico_linhas.py
├── 07_grafico_pizza.py
├── 08_grafico_regressao.py
├── requirements.txt
└── README.md
```

## Como Executar

1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```

2. Execute cada script individualmente:
   ```bash
   python 01_grafico_barras.py
   python 02_grafico_boxplot.py
   # ...
   ```
